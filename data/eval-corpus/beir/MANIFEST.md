# BEIR Eval Corpus — External Validity Layer

> **Workstream E Phase 2b.** External-validity baseline for the Cerid
> retrieval gate. The synthetic 20-doc corpus at `data/eval-corpus/v1/`
> measures internal lift (relative deltas across config changes); the
> BEIR datasets here measure absolute retrieval quality against a
> well-known public benchmark, providing comparability with published
> results.

## Why BEIR

BEIR (Benchmarking Information Retrieval, Thakur et al. 2021) is the
standard heterogeneous eval suite for retrieval systems. It ships
real-world documents + queries + binary relevance judgments (qrels)
across diverse domains. Cerid uses two of the smaller datasets to
balance scope (smaller = faster ingest + lower repo-size impact)
with signal coverage (different domains exercise different parts
of the retrieval pipeline).

| Dataset | Corpus | Queries | Domain (BEIR) | Cerid domain | License |
|---|---|---|---|---|---|
| **SciFact** | 5,183 | 300 | Scientific claim verification | `research` | CC BY 2.5 |
| **NFCorpus** | 3,633 | 323 | Nutrition / health information retrieval | `general` | CC BY-SA 4.0 |

Total: ~8.8K docs, 623 queries.

## How to seed

The corpus and dataset JSONL files are generated by the seed script,
not committed. Running the seed script downloads BEIR's official
distributions, parses them, and ingests every document via Cerid's
existing `ingest_content()` path with `sub_category="beir-{name}"`
for surgical wipe protection.

```bash
# From the host, after the cerid stack is up:
docker cp scripts/seed_beir_corpus.py ai-companion-mcp:/tmp/
docker exec -e PYTHONPATH=/app ai-companion-mcp \
    python /tmp/seed_beir_corpus.py
```

This:
1. Downloads `scifact.zip` (~2.8 MB) and `nfcorpus.zip` (~2.4 MB) from
   the BEIR mirror (`public.ukp.informatik.tu-darmstadt.de`) into the
   container's `/eval-corpus/beir-cache/` directory.
2. Extracts and parses `corpus.jsonl`, `queries.jsonl`,
   `qrels/test.tsv` (TREC qrel format).
3. Ingests every document into the appropriate Cerid domain with
   `sub_category="beir-{dataset_name}"`. Existing `content_hash`-based
   dedup makes the operation idempotent.
4. Writes `app/eval/datasets/beir_scifact.jsonl` and
   `app/eval/datasets/beir_nfcorpus.jsonl` carrying the REAL BEIR
   queries with `relevant_paths` referencing the just-ingested
   filenames. The harness's existing `_resolve_paths_to_artifact_ids`
   resolves these via Neo4j filename lookup at evaluate-time.

To seed only one dataset:

```bash
docker exec -e PYTHONPATH=/app -e CERID_BEIR_DATASETS=scifact \
    ai-companion-mcp python /tmp/seed_beir_corpus.py
```

## How to wipe

The standard wipe script handles BEIR families by default:

```bash
docker exec -e PYTHONPATH=/app ai-companion-mcp \
    python /tmp/wipe_eval_corpus.py
# Wipes all of: eval-corpus, beir-scifact, beir-nfcorpus
```

To wipe selectively:

```bash
docker exec -e PYTHONPATH=/app -e CERID_WIPE_FAMILIES=beir-scifact \
    ai-companion-mcp python /tmp/wipe_eval_corpus.py
```

## Provenance + attribution

* **BEIR project:** Thakur et al., 2021, "BEIR: A Heterogenous Benchmark
  for Zero-shot Evaluation of Information Retrieval Models",
  NeurIPS 2021. https://github.com/beir-cellar/beir
* **SciFact:** Wadden et al., 2020, "Fact or Fiction: Verifying
  Scientific Claims". https://github.com/allenai/scifact
* **NFCorpus:** Boteva et al., 2016, "A Full-Text Learning to Rank
  Dataset for Medical Information Retrieval".
  https://www.cl.uni-heidelberg.de/statnlpgroup/nfcorpus/

License compliance: SciFact (CC BY 2.5) and NFCorpus (CC BY-SA 4.0)
allow redistribution with attribution. Cerid neither redistributes
the corpora directly nor commits them — the seed script downloads
from the original sources and the operator is the recipient.

## Re-eval triggers (when to re-baseline)

Same triggers as the synthetic corpus baseline (see
`docs/EVAL_BASELINES.md`):

1. Embedding model or version changes.
2. Reranker model changes.
3. The BEIR dataset is upgraded by upstream (rare — these are
   stable academic benchmarks).
4. An intentional retrieval-pipeline change ships and the IR
   regression test fires (capture new baseline AFTER the change
   lands as a follow-up commit).
