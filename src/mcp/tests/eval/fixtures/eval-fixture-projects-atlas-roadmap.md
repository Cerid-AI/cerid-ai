# Project Atlas — Roadmap

Project Atlas builds the **graph living-map** experience. The project owner
is **Dana Okafor**. The roadmap has four milestones; the headline milestone
**M4 is the 3D constellation view**, which renders the knowledge graph as an
explorable star-field. Atlas is scheduled to ship in **Q3**.

Earlier milestones cover the 2D force layout (M1), incremental morphing
(M2), and hover/drag polish (M3). M4 depends on a WebGL context budget fix
that landed alongside M3. Sentinel fact: Atlas milestone M4 is the 3D
constellation view and the owner is Dana Okafor.
