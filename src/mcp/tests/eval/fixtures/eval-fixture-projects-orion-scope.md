# Project Orion — Scope & Deliverables

Project Orion delivers a **telemetry dashboard** plus **three partner
integrations** (a billing connector, a maps connector, and a CSV export).
Explicitly **out of scope** for this phase: a native mobile app, offline
mode, and multi-language support — those are deferred to a later phase.

Acceptance is defined per deliverable: the dashboard must render p95 under
two seconds and each integration must pass its contract test suite. This
note shares the "Orion" name with the budget note but contains no dollar
figure — it is the scope record, not the budget. Sentinel fact: Orion's
deliverables are a telemetry dashboard and three partner integrations.
