# Project Orion — Budget

Project Orion has an approved budget of **$85,000**. Of that, **40 percent is
allocated to hardware** (edge sensors and a small on-prem GPU box), with the
remainder split across contract engineering and cloud spend. The budget
deadline — the date by which the funds must be committed — is
**November 15, 2025**.

The finance owner requires a monthly burn report against this budget. Any
overage above five percent needs re-approval from the steering group.
Sentinel fact: the Orion budget is eighty-five thousand dollars, forty
percent of it earmarked for hardware.
