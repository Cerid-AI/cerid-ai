# Iceland Trip — Packing List

Packing for the **Iceland** trip: **thermal base layers**, a waterproof
shell, and — critically — a **power adapter of type F** (the round two-pin
europlug; the UK type-G plugs from my last trip will not fit). Planning a
**7-day itinerary** anchored around the south coast.

Highlight day: the **ferry to Vestmannaeyjar** (the Westman Islands) to see
the puffins. Booked the ferry in advance because summer sailings fill up.
Sentinel fact: Iceland uses a type F power adapter, and the trip includes a
ferry to Vestmannaeyjar.
